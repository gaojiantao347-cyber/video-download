# 前端功能文档 MVP

版本：V1.0  
日期：2026-04-28

## 1. MVP 目标

第一版前端只做“单链接下载”的最小闭环，不做大而全的视频平台爬虫后台。

核心流程：

```text
用户粘贴公开视频分享链接 -> 通过 Tauri 创建下载任务 -> 展示下载进度 -> 下载完成后提供打开文件/所在目录入口
```

## 2. 功能边界

### 2.1 MVP 支持

| 功能         | 说明                                         |
| ------------ | -------------------------------------------- |
| 单链接输入   | 用户粘贴抖音、快手公开视频分享链接           |
| 平台自动识别 | 根据链接域名识别抖音、快手                   |
| 创建下载任务 | 调用 Tauri `engine_rpc` facade 创建任务       |
| 任务状态展示 | 展示等待、下载中、成功、失败                 |
| 下载进度展示 | 下载中展示百分比进度条                       |
| 视频信息展示 | 展示标题、作者、封面、平台                   |
| 文件操作入口 | 下载完成后提供打开文件或打开所在目录按钮     |
| 错误提示     | 展示链接错误、平台不支持、解析失败、下载失败 |
| 重试失败任务 | 对失败任务重新提交原链接                     |

### 2.2 MVP 不支持

| 功能                   | 是否支持 | 原因                       |
| ---------------------- | -------: | -------------------------- |
| 用户登录               |   不支持 | 第一版没必要               |
| 批量下载               |   不支持 | 避免变成爬虫系统           |
| 后台管理系统           |   不支持 | 当前目标是工具，不是平台   |
| WebSocket 实时推送     |   不支持 | 轮询足够简单可靠           |
| 复杂历史记录管理       |   不支持 | 可先只保留当前页面任务状态 |
| Cookie/Token 输入      |   不支持 | 不处理登录态和权限绕过     |
| 私密/付费/DRM 视频下载 |   不支持 | 不做访问控制绕过           |

## 3. 页面规划

### 3.1 下载首页

MVP 只需要一个主页面。

| 区域       | 功能                       |
| ---------- | -------------------------- |
| 页面标题区 | 展示产品名称、支持平台说明 |
| 链接输入区 | 输入公开视频分享链接       |
| 操作按钮区 | 下载、清空                 |
| 当前任务区 | 展示任务卡片、状态、进度   |
| 使用说明区 | 提示仅支持公开视频链接     |

## 4. 组件规划

| 组件             | 职责                       |
| ---------------- | -------------------------- |
| `UrlInput`       | 输入、清空、基础格式校验   |
| `PlatformBadge`  | 展示识别到的平台           |
| `TaskCard`       | 展示单个任务信息           |
| `ProgressBar`    | 展示下载进度               |
| `ErrorMessage`   | 展示失败原因               |
| `FileActionButton` | 下载成功后打开文件或所在目录 |

> MVP 不需要复杂状态管理库。页面组件本地状态即可。

## 5. 交互流程

### 5.1 创建下载任务

```text
用户输入链接
  ↓
前端做基础校验
  ↓
点击“下载”
  ↓
Tauri invoke('engine_rpc') 调用 download.createTask
  ↓
Rust facade 返回 taskId
  ↓
前端开始轮询任务状态
```

### 5.2 查询下载进度

```text
每 1 秒通过 download.getTask 查询 taskId
  ↓
如果状态是 PENDING/DOWNLOADING，继续轮询
  ↓
如果状态是 SUCCESS/FAILED，停止轮询
```

### 5.3 下载文件

```text
任务状态为 SUCCESS
  ↓
展示“打开文件 / 打开所在目录”按钮
  ↓
点击后调用 download.getFile 获取本地文件路径
  ↓
通过 Tauri 文件/系统能力打开
```

## 6. 状态展示规则

| 后端状态      | 前端文案         | 前端表现            |
| ------------- | ---------------- | ------------------- |
| `PENDING`     | 等待下载         | 灰色状态标签        |
| `DOWNLOADING` | 正在下载         | 进度条              |
| `SUCCESS`     | 下载完成         | 成功标签 + 下载按钮 |
| `FAILED`      | 下载失败         | 错误信息 + 重试按钮 |

## 7. 表单校验

| 校验项   | 规则                     | 错误提示           |
| -------- | ------------------------ | ------------------ |
| 空值     | 链接不能为空             | 请输入视频分享链接 |
| URL 格式 | 必须是 http/https URL    | 请输入合法链接     |
| 支持平台 | 仅识别抖音、快手域名     | 暂不支持该平台     |
| 重复提交 | 同一链接下载中不重复提交 | 该链接正在下载中   |

## 8. API 依赖

前端不调用 HTTP API，统一通过 Tauri `invoke('engine_rpc')` 发送 JSON-RPC envelope。

### 8.1 创建任务

调用 `download.createTask`。

```json
{
  "url": "https://v.douyin.com/xxxxxx/",
  "outputDir": "D:/Videos",
  "removeWatermark": true,
  "allowFallback": true
}
```

响应：

```json
{
  "taskId": "task-1770000000000-1",
  "status": "PENDING",
  "removeWatermark": true
}
```

### 8.2 查询任务

调用 `download.getTask`。

### 8.3 获取文件信息

调用 `download.getFile`，返回本地文件路径，不传输文件字节。

## 9. 异常提示文案

| 场景         | 文案                             |
| ------------ | -------------------------------- |
| 链接为空     | 请输入视频分享链接               |
| 平台不支持   | 当前仅支持抖音、快手公开视频链接 |
| 创建任务失败 | 创建下载任务失败，请稍后重试     |
| 解析失败     | 视频解析失败，链接可能已失效     |
| 下载失败     | 视频下载失败，请稍后重试         |
| 文件不可用   | 文件不存在或已被清理             |

## 10. 验收标准

| 编号      | 验收项                                       |
| --------- | -------------------------------------------- |
| F-MVP-001 | 用户可以输入抖音或快手分享链接               |
| F-MVP-002 | 前端能识别平台并展示平台标识                 |
| F-MVP-003 | 点击下载后能创建任务                         |
| F-MVP-004 | 页面能展示等待下载、下载中、成功、失败状态   |
| F-MVP-005 | 下载中能展示进度条                           |
| F-MVP-006 | 下载成功后能点击按钮打开文件或所在目录       |
| F-MVP-007 | 下载失败时能展示明确失败原因                 |
| F-MVP-008 | 不提供批量抓取、登录态输入、私密视频下载入口 |
