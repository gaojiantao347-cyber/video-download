# 前端页面布局与样式规划文档 (Tauri + Vue + Element Plus 版)

版本：V1.2
日期：2026-04-28
适用范围：Video Download 桌面端项目（对齐《前端技术栈规划》V1.0）

---

## 1. 设计语言与品牌形象

### 1.1 核心理念

- **管理后台化 (Admin Dashboard Style)**：由于定位于“大而全的视频平台爬虫软件”，UI 风格向专业的管理后台看齐，强调数据的条理性和操作的批量化。
- **Element Plus 标准规范**：严格遵循 Element Plus 的设计规范（间距、圆角、阴影），确保组件间的高度协调。

### 1.2 色彩与主题

- **品牌主色**：`#409EFF` (Element Plus 默认蓝) —— 用于主操作、链接、进度条。
- **状态语义色**：
  - `SUCCESS`: `#67C23A` (解析完成、下载成功)
  - `WARNING`: `#E6A23C` (限速中、空间不足)
  - `DANGER`: `#F56C6C` (任务失败、授权失效)
- **背景体系**：采用灰白层级背景 (`#F2F3F5`)，卡片区域使用白色背景 (`#FFFFFF`) 以突出内容。

## 2. 页面布局深度规划 (侧边栏架构)

由于项目包含工作台、内容库、设置等多个模块，采用 **Classic Sidebar Layout**。

### 2.1 整体骨架

- **Sidebar (左侧导航)**：
  - 宽度：固定 220px (支持折叠至 64px)。
  - 内容：应用 Logo + 导航菜单（按 `features` 组织：工作台、平台管理、采集源、任务队列、内容库等）。
- **Main Header (顶部栏)**：
  - 左侧：面包屑导航 (Breadcrumb)。
  - 右侧：**本地下载引擎状态灯**（绿色/红色）、当前网速显示、设置图标。
- **Content (主内容区)**：
  - 采用 `el-main` 容器，带内部滚动条。
  - 页面顶部统一放置 `PageHeader`，包含标题及关键操作按钮。

### 2.2 核心模块页面布局

- **工作台 (Dashboard)**：
  - 顶部：`el-statistic` 统计卡片（今日下载、成功率、存储占用）。
  - 中部：**ECharts 趋势图**（24小时下载量、平台占比）。
  - 底部：异常告警列表（最近失败的任务）。
- **任务/队列页 (Task Queue)**：
  - 采用 **Card + Table 混合布局**。
  - 顶部搜索栏：支持平台筛选、状态筛选。
  - 列表区：`el-table` 展示任务，列包含：封面(缩略图)、标题、进度( `el-progress` )、操作。
- **内容库 (Content Library)**：
  - **大表格布局**：支持多维度筛选（作者、平台、标签）。
  - 支持“瀑布流”视图切换，方便预览视频封面。

## 3. 桌面端特有交互 (Tauri 增强)

### 3.1 标题栏与窗口控制

- **无边框自定义标题栏**：在 `layouts/` 中实现。
  - 利用 `-webkit-app-region: drag` 实现顶部区域拖拽。
  - 自定义 `Minimize`, `Maximize`, `Close` 按钮。
- **本地下载引擎状态交互**：
  - 当下载引擎检查中，显示全局 `el-loading` 遮罩，文案“正在检查下载引擎...”。
  - 引擎心跳丢失时，顶部栏弹出 `el-alert` 提示“本地下载引擎连接断开，请稍后重试”。

### 3.2 系统级交互

- **Dialog 对话框**：在选择“下载目录”时，调用 Tauri `dialog.open`，UI 上通过 `el-input` 只读显示路径，右侧带“选择”按钮。
- **通知中心**：利用 `el-notification` 同步显示系统的原生通知内容。

## 4. 技术栈组件映射

| 功能模块   | 对应组件 / 技术                                |
| ---------- | ---------------------------------------------- |
| 列表展示   | `el-table` + `el-pagination`                   |
| 表单提交   | `el-form` (采集源创建、系统设置)               |
| 进度流转   | `el-steps` (任务创建向导)                      |
| 数据可视化 | **ECharts** (存储趋势、平台分布)               |
| 状态提示   | `el-tag` (PENDING/DOWNLOADING/SUCCESS)         |
| 全局状态   | **Pinia** (当前正在运行的任务总数、引擎健康度) |
| 异步数据   | **TanStack Query** (自动轮询队列进度)          |

---

## 5. 样式组织规范 (SCSS)

- **全局变量**：`src/assets/styles/variables.scss` 定义 Element Plus 覆盖变量。
- **模块样式**：按 `features/` 目录组织，使用 `scoped` 样式避免污染。
- **实用类**：利用 Tailwind CSS 提供的 Utility Classes 处理边距、对齐（配合 `unocss` 或直接引用）。

---

## 6. 响应式与体验优化

- **窗口缩放**：当窗口宽度小于 1024px 时，侧边栏自动折叠。
- **高风险确认**：删除视频文件、清空任务队列等操作必须调用 `el-message-box.confirm`。
- **热键反馈**：按下全局快捷键时，UI 上给出短暂的 `Message` 提示。
