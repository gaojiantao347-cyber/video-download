# 前端功能文档 后续规划

版本：V2.0  
日期：2026-04-28

## 1. 后续产品定位

MVP 阶段先做单链接下载闭环。后续阶段的目标不是继续做一个小工具，而是演进为一个“大而全的视频平台爬虫软件”。

后续前端需要支持：

```text
多平台接入 -> 采集源管理 -> 爬虫任务编排 -> 下载队列监控 -> 内容资产管理 -> 数据统计分析 -> 系统配置运维
```

## 2. 总体功能地图

| 功能域       | 说明                                                           |
| ------------ | -------------------------------------------------------------- |
| 工作台       | 展示任务总览、采集进度、成功率、失败告警                       |
| 平台管理     | 管理抖音、快手、B 站、小红书、微博、西瓜视频等平台能力         |
| 采集源管理   | 管理视频链接、作者主页、合集、话题、关键词、搜索结果等采集入口 |
| 爬虫任务管理 | 创建、编辑、暂停、恢复、取消、重跑爬虫任务                     |
| 下载队列     | 展示等待中、解析中、下载中、已完成、失败任务                   |
| 内容库       | 管理已采集视频、封面、作者、标签、来源、文件状态               |
| 文件管理     | 管理本地文件、文件大小、保存路径、清理策略                     |
| 规则配置     | 配置采集深度、分页数量、并发数、限速、去重策略                 |
| 账号与授权   | 管理用户主动授权的平台账号或访问凭证                           |
| 统计分析     | 展示平台分布、任务趋势、下载量、失败率、存储占用               |
| 系统设置     | 管理下载目录、并发限制、保留时间、通知方式                     |
| 操作审计     | 记录任务创建、配置变更、文件删除等操作                         |

## 3. 页面规划

### 3.1 工作台首页

| 模块         | 功能                                   |
| ------------ | -------------------------------------- |
| 今日采集概览 | 今日新增任务、成功数、失败数、下载总量 |
| 运行中任务   | 展示当前正在执行的爬虫任务             |
| 平台健康状态 | 展示各平台解析成功率和最近失败原因     |
| 存储概览     | 展示总文件数、总大小、剩余空间         |
| 异常告警     | 展示连续失败、磁盘不足、平台解析异常   |

### 3.2 平台管理页

| 功能     | 说明                                               |
| -------- | -------------------------------------------------- |
| 平台列表 | 展示已支持平台                                     |
| 平台状态 | 启用、停用、维护中                                 |
| 平台能力 | 单视频、作者主页、合集、话题、搜索、评论等能力标记 |
| 平台配置 | 域名规则、默认并发、默认限速、解析策略             |
| 平台测试 | 输入样例链接测试解析能力                           |

### 3.3 采集源管理页

| 采集源类型    | 说明                      |
| ------------- | ------------------------- |
| 单视频链接    | 单条公开视频链接          |
| 批量视频链接  | 多条用户输入链接          |
| 作者主页      | 采集指定作者公开作品      |
| 合集/播放列表 | 采集公开合集内视频        |
| 话题/标签页   | 采集指定话题下公开视频    |
| 关键词搜索    | 按关键词采集公开搜索结果  |
| 导入文件      | 从 CSV/TXT 导入待采集链接 |

页面功能：

| 功能         | 说明                           |
| ------------ | ------------------------------ |
| 新增采集源   | 选择平台和采集源类型           |
| 采集源分组   | 按业务、平台、用途分组         |
| 启停采集源   | 控制采集源是否参与任务         |
| 采集源校验   | 校验链接格式和平台支持情况     |
| 最近采集结果 | 展示最近一次采集数量和失败原因 |

### 3.4 爬虫任务管理页

| 功能       | 说明                                 |
| ---------- | ------------------------------------ |
| 创建任务   | 基于采集源创建一次性或周期性任务     |
| 任务模板   | 保存常用任务配置                     |
| 任务优先级 | 高、中、低                           |
| 任务状态   | 等待、运行中、暂停、完成、失败、取消 |
| 任务控制   | 暂停、恢复、取消、重跑               |
| 失败重试   | 对失败任务按策略重试                 |
| 任务日志   | 查看解析、下载、去重、失败详情       |

### 3.5 下载队列页

| 功能     | 说明                               |
| -------- | ---------------------------------- |
| 队列分组 | 等待中、解析中、下载中、成功、失败 |
| 实时进度 | 展示每个下载项进度                 |
| 批量操作 | 批量暂停、恢复、取消、重试         |
| 失败过滤 | 按失败类型过滤                     |
| 任务详情 | 查看来源链接、目标文件、错误信息   |

### 3.6 内容库页面

| 功能     | 说明                                       |
| -------- | ------------------------------------------ |
| 视频列表 | 展示已采集视频                             |
| 视频详情 | 标题、作者、封面、平台、发布时间、来源链接 |
| 标签管理 | 手动或自动标签                             |
| 去重状态 | 展示重复视频标记                           |
| 文件状态 | 未下载、已下载、文件丢失、已清理           |
| 重新下载 | 对文件丢失的视频重新下载                   |
| 导出数据 | 导出 CSV/JSON                              |

### 3.7 作者库页面

| 功能     | 说明                           |
| -------- | ------------------------------ |
| 作者列表 | 展示已采集作者                 |
| 作者详情 | 昵称、平台、主页链接、作品数量 |
| 作品列表 | 查看该作者下的视频             |
| 采集记录 | 查看该作者历史采集任务         |
| 关注状态 | 是否纳入周期采集               |

### 3.8 文件管理页

| 功能     | 说明                             |
| -------- | -------------------------------- |
| 文件列表 | 展示本地已下载文件               |
| 存储占用 | 按平台、日期、任务统计大小       |
| 文件清理 | 按时间、平台、状态清理           |
| 文件校验 | 检查数据库记录和本地文件是否一致 |
| 路径查看 | 查看文件保存位置                 |

文件删除必须二次确认，并展示影响范围。

### 3.9 系统设置页

| 设置项       | 说明                             |
| ------------ | -------------------------------- |
| 下载目录     | 默认文件保存目录                 |
| 最大并发数   | 全局下载并发限制                 |
| 平台并发数   | 每个平台单独限制                 |
| 请求间隔     | 控制采集请求频率                 |
| 最大采集深度 | 控制分页和递归采集范围           |
| 文件保留策略 | 配置自动清理规则                 |
| 通知配置     | 任务失败、磁盘不足、任务完成通知 |

### 3.10 账号与授权页

| 功能         | 说明                           |
| ------------ | ------------------------------ |
| 授权账号列表 | 展示用户主动添加的平台授权信息 |
| 授权状态     | 正常、失效、需重新授权         |
| 权限范围     | 展示该授权允许访问的内容范围   |
| 失效提醒     | 授权过期或不可用时提醒         |
| 删除授权     | 用户主动删除授权信息           |

注意：前端不得提供窃取浏览器 Cookie、绕过验证码、绕过付费或私密权限的入口。

## 4. 核心前端交互流程

### 4.1 创建爬虫任务

```text
选择平台
  ↓
选择采集源类型
  ↓
填写链接/关键词/作者主页
  ↓
配置采集深度、并发、是否下载文件
  ↓
预检查
  ↓
提交任务
  ↓
进入任务详情页查看执行进度
```

### 4.2 周期采集任务

```text
创建采集源
  ↓
设置执行周期
  ↓
配置增量采集规则
  ↓
任务自动进入调度队列
  ↓
前端展示下次执行时间和最近执行结果
```

### 4.3 内容检索流程

```text
进入内容库
  ↓
按平台/作者/标签/时间/任务筛选
  ↓
查看视频详情
  ↓
执行下载、重新下载、导出、删除等操作
```

## 5. 前端状态模型

### 5.1 爬虫任务状态

| 状态        | 前端展示 |
| ----------- | -------- |
| `CREATED`   | 已创建   |
| `WAITING`   | 等待调度 |
| `RUNNING`   | 运行中   |
| `PAUSED`    | 已暂停   |
| `COMPLETED` | 已完成   |
| `FAILED`    | 失败     |
| `STOPPED`   | 已停止   |

### 5.2 采集项状态

| 状态          | 前端展示 |
| ------------- | -------- |
| `DISCOVERED`  | 已发现   |
| `COLLECTING`  | 采集中   |
| `PARSED`      | 已解析   |
| `DUPLICATED`  | 重复内容 |
| `DOWNLOADING` | 下载中   |
| `DOWNLOADED`  | 已下载   |
| `SKIPPED`     | 已跳过   |
| `FAILED`      | 失败     |

## 6. 后续 API 依赖方向

| API 类别     | 前端用途                         |
| ------------ | -------------------------------- |
| 平台 API     | 平台列表、平台能力、平台测试     |
| 采集源 API   | 采集源增删改查                   |
| 爬虫任务 API | 创建、暂停、恢复、取消、重跑任务 |
| 队列 API     | 查询下载队列和实时进度           |
| 内容库 API   | 查询视频、作者、标签、文件状态   |
| 文件 API     | 下载、重新下载、清理、校验文件   |
| 统计 API     | 工作台图表和报表                 |
| 设置 API     | 查询和修改系统配置               |
| 审计 API     | 查询操作记录                     |

## 7. 权限与安全交互

| 操作              | 前端要求                   |
| ----------------- | -------------------------- |
| 删除文件          | 二次确认                   |
| 批量取消任务      | 二次确认                   |
| 修改下载目录      | 二次确认                   |
| 修改并发/限速配置 | 展示风险提示               |
| 添加授权账号      | 明确展示授权用途和权限范围 |
| 导出数据          | 明确导出字段范围           |
